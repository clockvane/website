## ADR-002 conformance (existing evidence; no infrastructure changed)
- **Build once, deploy many** ("Every environment deploys that same artifact; nothing is rebuilt"): **met.** One build, in ci run
  43637919918, produced `site-f432e5a…` (artifact ID 14130413924). Staging and production both downloaded that artifact ID with the same digest
  `baa17b8e…` (deploy-staging `deploy` log at 20:38:41 UTC, `deploy-production` log at 20:56:43 UTC). The checksum of its `SHA256SUMS`
  (`a29f462d…c992f`) is the value staging recorded and production verified before deploying. Neither job runs a build. A local check
  on 2026-11-15 matched it: the downloaded artifact's `SHA256SUMS` hashes to `a29f462d…c992f`, and the set of `/_astro/*` asset URLs
  in its `index.html` is identical to the live production home page. The adapter changes the
  environment's enquiry endpoint and headers at deploy time (#185, `prepare-production.sh`). That is the configuration step ADR-002
  allows, not a rebuild.
- **Environments**, production protection ("GitHub environment `production` with the owner as required reviewer"): **met for this run.**
  `release.yml` job `deploy-production` declares `environment: production`. The job sat in `waiting` for about 1.5 minutes and ran only
  after the owner's recorded approval. The Cloudflare token is an environment secret, released only after approval. The environment's settings are not
  readable by agents (human-only API). The settings themselves come from #164 ("Done": required reviewer, tags `v*` only), and
  this approval record confirms them in practice.

## Rollout and rollback

The release commit is **the merge commit of this PR**. After both `ci` and the complete `deploy-staging` workflow
pass on that SHA, DevOps records their run links in the release PR and a maintainer pushes `v1.0.0` on that commit
([release.md step 5](../devops/release.md#steps)); no workflow pushes the tag. `release.yml` then

or fixing forward with `v1.0.1`. Steps: [release.md § First go-live](../devops/release.md#first-go-live-v100).
